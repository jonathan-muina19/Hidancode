Exercice 2(CSS sélecteurs)

Crée une classe box et donne-lui :

  • un fond gris clair
  • un padding de 15px
  • un arrondi de 10px

Correction (exemple)

.box {
  background: #eee;
  padding: 15px;
  border-radius: 10px;
}
